# PanelBuilder — demostración pública

Vista previa experimental de PanelBuilder v0.11 para probar el editor desde el navegador: **https://sergioroqueh.github.io/panelbuilder-demo/**.

Este repositorio aloja solamente HTML, CSS y JavaScript estáticos de la aplicación. El código fuente de desarrollo, las pruebas y la documentación privada están separados.

### Versión disponible

Consulta [docs/build-info.json](docs/build-info.json) para conocer el commit exacto de la rama experimental privada del que procede esta copia. Cada actualización de `main/docs` se publica mediante GitHub Pages.

### Avisos importantes

- Prototipo, no herramienta certificada ni apta todavía para fabricar cuadros eléctricos.
- Las referencias comerciales pueden ser candidatas por capacidad nominal, pero ninguna se valida automáticamente para instalación ni fabricación.
- Los diseños se conservan en el almacenamiento local del navegador; usa **Exportar JSON** antes de cambiar de equipo o borrar datos.
- Los importes comerciales son documentales y su vigencia o tratamiento de IVA pueden estar pendientes.

La sincronización automática desde el repositorio privado requiere un permiso de GitHub configurado por el propietario. Mientras tanto, las actualizaciones se publican mediante una copia controlada.
