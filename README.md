# PanelBuilder — Demo pública v0.11

Este repositorio aloja **solo una copia estática y experimental de PanelBuilder** para revisión visual desde el navegador. El repositorio de desarrollo completo es privado e independiente; **no contiene código fuente del proyecto fuera del conjunto web publicado**.

## Acceso

Cuando GitHub Pages esté activado en **Settings → Pages → Deploy from a branch → main /docs**, la demo estará en: **https://sergioroqueh.github.io/panelbuilder-demo/**.

## Procedencia

Origen: rama experimental `feat/v0.11-unifilar-tecnico` de `sergioroqueh/panelbuilder-dev`. Versión copiada: `35fb90cd7b568a1d1a8ccfbe4b2085ab6c9845e3`. Consulta `docs/build-info.json` para el identificador de versión; el propio editor lo muestra si se sirve desde GitHub Pages.

## Avisos

- Herramienta **experimental**, sin validación UNE/IEC/REBT ni aptitud para fabricación de cuadros.
- La biblioteca comercial **no implica** compatibilidad técnica automática, ficha de montaje aprobada ni precio vigente.
- **Sin cuentas ni nube**: los diseños quedan en el almacenamiento local de cada navegador. Usa **Exportar JSON** para conservarlos antes de limpiar datos, cambiar de navegador o de dominio.
- La demo pública no contiene secretos, expedientes, pedidos ni la documentación privada del desarrollo.

## Actualizaciones

GitHub Pages volverá a publicar automáticamente cuando cambien archivos de `main /docs` tras configurarlo. La sincronización desde el repositorio privado a este repositorio público necesita un permiso explícito de escritura entre repositorios; hasta establecerlo, la actualización de archivos debe repetirse de forma controlada.
